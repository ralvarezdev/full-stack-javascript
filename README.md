# full-stack-javascript

**Note:** This repository is archived and read-only.

Practice exercises from [The Odin Project](https://www.theodinproject.com/)'s Full Stack JavaScript path.

## Contents

- **`html-css-intermediate/tables/`** — HTML tables exercise: a "Planets data" page (`index.html`) using `<caption>`, `<colgroup>` and `<thead>` with `minimal-table.css`, plus `blank-template.html` and the source data `planets-data.txt`.
- **`html-css-intermediate/css-units/`** — CSS values and units: `length-download.html`, `color-download.html`, `position-download.html` and `star.png`.

## Running

Static pages with no build step. Open the HTML files in a browser, for example `xdg-open html-css-intermediate/tables/index.html`.
